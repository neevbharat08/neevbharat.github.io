# Neev Bharat — Futuristic Cyber Portfolio

A high-tech, futuristic portfolio website built for Neev Bharat, 1st Year B.Tech student in Computer Science & Engineering (AI & ML) at DRK Institute of Science and Technology.

## 🚀 Features
- **Design Aesthetic:** Obsidian Void Dark Mode with Crimson/Neon Red (`#ff2a5f`) accents and glassmorphism.
- **Interactive Holographic Core:** Counter-rotating 3D orbital rings, pulsing radar core, and zero-G floating tags (`CODE`, `LEARN`, `BUILD`).
- **Interactive Particle Matrix:** HTML5 Canvas particle network that connects with laser beams and reacts to cursor movements.
- **Audio Synthesizer (SFX):** Integrated Web Audio API sound effects with a toggle button (`SFX ON/OFF`).
- **Interactive Q&A Zone:** Smoothly expanding accordion with answer animations.
- **Cyber Contact Form:** Encrypted transmission simulation with client-side validation and toast notifications.
- **Pre-generated Resume PDF:** Downloadable directly from the site.

## 📁 File Structure
```
neev-portfolio/
├── index.html        # Main HTML structure
├── style.css         # Styling and animations
├── script.js         # Canvas particles, SFX, and interactions
├── server.ps1        # Local development HTTP server script
└── assets/
    └── resume/
        └── resume.pdf # Formatted resume PDF
```

## 💻 How to Run Locally
### Option 1: Double-click
Simply double-click `index.html` to open it in any web browser.

### Option 2: Run the Local Server (Recommended)
Open PowerShell in this folder and run:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then visit: `http://localhost:8080/`

## 🌐 Deploy to Web
You can deploy this site in seconds for free using:
- **GitHub Pages:** Push these files to a GitHub repository, go to `Settings > Pages`, and select `main` branch.
- **Netlify / Vercel:** Drag and drop this folder directly onto Netlify or Vercel dashboard.
